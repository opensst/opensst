opensst package repository

Static package repositories serving the latest release of opensst (the sst command), currently version {{VERSION}}. This site is generated by the release pipeline; the package files here are byte-identical to the GitHub release assets.

apt (Debian, Ubuntu)

Add to /etc/apt/sources.list.d/opensst.list, then apt update && apt install opensst:

deb [trusted=yes] https://opensst.github.io/opensst/deb ./

dnf (Fedora, RHEL)

Add to /etc/yum.repos.d/opensst.repo, then dnf install opensst:

[opensst]
baseurl=https://opensst.github.io/opensst/rpm
gpgcheck=0

pacman (Arch Linux)

Add to /etc/pacman.conf, then pacman -Syu opensst:

[opensst]
Server = https://opensst.github.io/opensst/arch
SigLevel = Never

Trust model

These repositories are not signed. Transport is HTTPS, the publisher is this GitHub repository, and the package bytes are identical to the release assets — verify them against the SHA256SUMS published on the release page. The per-repository settings above ([trusted=yes], gpgcheck=0, SigLevel = Never) scope the opt-in to this repository only.

Support floor: apt ≥ 1.5, dnf4-era clients, pacman ≥ 6. Only the latest release is served; older versions remain downloadable from the release pages. Upgrades through your system package manager complement sst update — either channel installs the same bytes.
